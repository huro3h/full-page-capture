# Full Page Capture

スクロールが必要なページ全体を1枚のPNGとして撮影するChrome拡張 (MV3)。

ブラウザには「ページ全体を撮る」APIが無く、`chrome.tabs.captureVisibleTab` で
**今見えている範囲**しか撮れない。そこでページをスクロールさせながら連写し、
到達したスクロール座標を頼りに1枚へ合成している。

## 主な機能

- **ページ全体を撮影** — ツールバーのアイコンをクリック
- **表示範囲だけを撮影** — ショートカットから
- 撮影中は固定ヘッダー・sticky要素・スクロールバー・アニメーションを自動で無効化し、
  縞模様や写り込みを防ぐ
- ページ本体がスクロールしない作りでも、**中のスクロール領域や同一オリジンiframeを
  自動で見つけて撮影する**
- **高速モード（既定）** — Chrome の開発者ツールと同じ仕組みでページ全体を1回で撮る。
  長いページで5〜10倍速い
- 撮影後、結果ページで寸法を確認して **PNG / JPEG / PDF** として保存
- **保存ファイル名をテンプレートで設定できる**（日時・タイトル・ドメインなどの変数つき）

### ショートカットキー

**デフォルトでは未割り当て**。他の拡張やOSのショートカットと衝突しないよう、
意図的に `suggested_key` を定義していない。使う場合は
`chrome://extensions/shortcuts` から手動で割り当てる。

| コマンド | 内容 |
| --- | --- |
| `01_capture-full-page` | ページ全体を撮影 |
| `02_capture-visible` | 表示されている範囲だけを撮影 |

## インストール

1. `chrome://extensions` を開く
2. 「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選択

権限は `activeTab` / `scripting` / `storage` / `debugger`。ホスト権限を常時持たないので、
アイコンをクリックした(またはショートカットを押した)タブだけを対象にする。

`debugger` は高速モードで使う。この権限はウェブストアの審査が厳しいため、
**このプロジェクトはウェブストアへ公開せず、未パッケージのまま使う前提**にしている。

## 撮影方法

| モード | 仕組み | 速度(MDNの長いリファレンス) |
| --- | --- | --- |
| **高速**（既定） | `chrome.debugger` 経由で CDP の `Page.captureScreenshot({captureBeyondViewport:true})` を1回 | **6.4秒** |
| 連写 | `captureVisibleTab` でスクロールしながら撮って合成 | 31.4秒 |

高速モードの撮影中だけ、ブラウザ上部に「デバッグしています」という通知バーが出る
(ビューポートが56px縮む)。

次の場合は**自動的に連写へ切り替わる**（理由が結果ページに表示される）。

- 本文がiframeやページ内のスクロール領域にある — CDPはタブの最上位ドキュメントしか撮れないため
- 画像の辺が 64000px を超える — この上限を超えると**エラーにならず全面が真っ黒な画像**が返るため

設定ページで「連写」を明示的に選ぶこともできる。

## 使い方

撮りたいページでツールバーのアイコンをクリックすると、バッジに撮影枚数が出る。
完了すると結果ページが新しいタブで開くので、保存したい形式のボタンを押す。

| 形式 | 内容 |
| --- | --- |
| PNG | 無圧縮。文字がにじまないので既定の選択 |
| JPEG | 品質92%。縦長のページだとPNGの半分以下になる |
| PDF | 幅をA4に合わせて埋め込む。既定は1ページにまとめる形式 |

PDFは既定で**「1ページにまとめる」**（縦に長い1枚のPDF）。
「A4縦で分割」を選べば印刷向けのページ分割になる。
1ページ形式はページの辺が長くなりすぎると多くのPDFビューアで開けなくなるため、
上限 (14400pt = 200インチ) を超える画像では自動的に「A4縦で分割」へ切り替わる。

### ファイル名の設定

`chrome://extensions` の拡張機能詳細から「拡張機能のオプション」を開くか、
結果ページに表示されているファイル名をクリックすると設定ページが開く。

既定は `%TITLE%_%DATE%-%TIME%` (例: `記事タイトル_20260911-143005.png`)。
使える変数:

| 変数 | 内容 | 変数 | 内容 |
| --- | --- | --- | --- |
| `%TITLE%` | ページタイトル | `%YEAR%` | 年 (2026) |
| `%DOMAIN%` | ドメイン名 | `%MONTH%` | 月 (09) |
| `%PATH%` | URLのパス | `%DAY%` | 日 (11) |
| `%URL%` | URL全体 | `%HOUR%` | 時 (14) |
| `%DATE%` | 日付 (20260911) | `%MIN%` | 分 (30) |
| `%TIME%` | 時刻 (143005) | `%SEC%` | 秒 (05) |
| `%WIDTH%` | 画像の幅 (px) | `%HEIGHT%` | 画像の高さ (px) |

入力しながらプレビューで結果を確認でき、変数の綴りを間違えると警告が出る。
拡張子は保存する形式に応じて自動で付く。ファイル名の最大文字数も設定できる
(長いタイトルをそのまま使うとOSの上限に当たって保存できないことがあるため)。

## 制限

- `captureVisibleTab` は1秒あたり2回までのレート制限があるため、
  長いページほど時間がかかる (おおむね 0.5秒 × 画面数)
- 遅延読み込み画像や仮想スクロール (React Virtualized など) は、
  スクロールで中身が入れ替わるため原理的に繋げない
- 無限スクロールのページは、撮影開始時点の高さで打ち切る
- **クロスオリジンのiframeが本体のページは撮影できない**。
  同一オリジンのiframeやページ内のスクロール領域は自動で見つけて撮影する
- Chromeのcanvas上限 (辺65535px / 面積約2^28px) を超える場合は自動で縮小する
- **Chrome ウェブストア (`chromewebstore.google.com`) は撮影できない**。
  Chromium が拡張機能によるスクリプト実行を禁じているページで、
  `<all_urls>` を付けても `The extensions gallery cannot be scripted.` で拒否される。
  FireShot を含むどの拡張機能でも同じ
- `chrome://` や他の拡張機能のページも同様に撮影できない
- ローカルファイル (`file://`) を撮るには、`chrome://extensions` の拡張機能詳細で
  「ファイルの URL へのアクセスを許可する」をONにする必要がある

撮影できないページでアイコンを押すと、バッジに赤い `!` が出る。
アイコンにマウスを乗せると理由が表示される
(ページを操作できない状況なので、ページ内に通知を出す手段がない)。

## テスト

```bash
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm i playwright
node test/e2e.js
```

Brave Browser Nightly を使って実際に撮影し、合成画像のピクセルを直接検証する。
